Lens & Light Photography is a personal photography website that showcases my interest in photography, nature, landscapes, wildlife and beautiful scenery. The website introduces me, displays a collection of photographs, and provides contact information for visitors.

## 2. JavaScript Enhancements

JavaScript was added to improve the functionality and interactivity of the existing photography website.

The enhancements allow visitors to interact with different website elements, view photographs through a slideshow, see the current time, and navigate back to the top of the page.

The JavaScript code is stored in an external file named `script.js` inside the `js` folder.

## 3. JavaScript Features Implemented

The following five JavaScript features were implemented:

### 1. Digital Clock

Displays the current time on the homepage. The clock updates automatically every second using JavaScript's Date object and setInterval() function.

### 2. Show and Hide About Me

Allows visitors to show or hide the About Me description by clicking a button. JavaScript changes the visibility of the content and updates the button text.

### 3. Photography Slideshow

Displays photographs from the website's portfolio in a slideshow. Visitors can browse through the photographs using the Previous and Next buttons.

### 4. Back to Top Button

Displays a button when visitors scroll down the page. Clicking the button smoothly returns the visitor to the top of the website.

### 5. Automatic Copyright Year

Automatically displays the current year in the website footer. JavaScript retrieves the current year using the Date object, so the copyright year does not need to be changed manually.

## 8. Responsive Design

The website uses CSS media queries to adjust its layout for different screen sizes.

On smaller screens, the navigation links are rearranged, the About section changes to a vertical layout, and the photography gallery changes from two columns to one column.

The images and slideshow also adjust their dimensions to fit smaller screens.



## 9. Reflection

During this project, I implemented five JavaScript features to improve the functionality of my Lens & Light Photography website. These features include a digital clock, a show and hide About Me button, a photography slideshow, a Back to Top button, and an automatic copyright year.

One challenge I encountered was getting the slideshow buttons to work correctly. Initially, the Next and Previous buttons did not change the displayed photographs as expected. I worked on correcting the JavaScript so that the images, captions and image counter update together. I also had to make sure the correct image paths were being used.

Through this project, I learned how JavaScript can make a website more interactive. I gained a better understanding of DOM manipulation, event listeners, functions, arrays and how JavaScript can update HTML elements without reloading the page.

I also gained experience using Git branches and Pull Requests. Creating a separate branch allowed me to work on the JavaScript enhancements without directly changing the main branch. Using a Pull Request helped me understand how changes can be reviewed and merged into the main project.

Overall, this project helped me to improve my knowledge and skills using HTML, CSS and JavaScript to develop interactive websites.
